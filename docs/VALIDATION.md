# Проверка сборки

Проверено в среде Node.js 25.9.0, npm 11.14.1.

- `npm run build --prefix client` — успешно, Vite 6.4.5, 139 модулей.
- Проверка синтаксиса серверных JS-файлов — успешно.
- `cd server && npm test` — 4 проверки прошли: принятие/отклонение JWT,
  неверная подпись, недопустимые параметры папки, создание каталогов и дубликаты.
  Эти проверки не используют базу данных.

Полный сценарий регистрации → входа → создания папки с реальной MongoDB
и визуальная проверка в браузере не выполнены. Docker daemon в среде не запущен.
Порядок ручной проверки описан в README и EXPLANATION_RU.

Зависимости React/Redux/Mongoose сохранены близко к старому учебному курсу.
Установка npm сообщает об устаревших пакетах; аудит безопасности и подготовка
к публичному размещению не входили в проверку этого учебного этапа.
